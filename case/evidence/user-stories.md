# Draft user stories and acceptance criteria

Document ID: `ABS-US-001`  
Version: `1.0`  
Classification: `SYNTHETIC-PUBLIC`

[US-001] As an applicant, I want a simple verification process so that I can open an account without difficulty. Acceptance criteria: not supplied.
[US-002] As an applicant, I want to save and resume my application so that I do not lose my work. Acceptance criteria: not supplied.
[US-003] As an applicant, I want my account activated immediately after I submit my documents so that I can use the service at once. Acceptance: activation occurs without waiting for another person.
[US-004] As an Onboarding Specialist, I want a queue filtered by status so that I can focus on pending work. Acceptance: selecting one or more documented statuses returns only applications in those statuses and shows the active filters.
[US-005] As a Sales Manager, I want the best notification experience so that I know when a customer is ready. Acceptance criteria: not supplied.
[US-006] As a Support Analyst, I want account details. Acceptance criteria: not supplied.
[US-007] As an applicant, I want to receive the decision soon so that I can plan my next step. Acceptance criteria: not supplied.
[US-008] As an applicant, I want my unfinished form stored and reopened later so that I can continue where I stopped. Acceptance criteria: not supplied.
[US-009] As a Risk Reviewer, I want every decision to require a reason code so that the audit trail explains the outcome. Acceptance: APPROVE and REJECT actions are blocked until one configured reason code is selected and saved with the reviewer and timestamp.
[US-010] As an applicant, I want to update my phone and email and delete my profile so that I control my profile. Acceptance criteria: not supplied.
